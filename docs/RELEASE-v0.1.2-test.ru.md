# GerdaLRS v0.1.2-test

Тёмная веб-морда устройства и выбор regulatory domain на LR1121. Продолжение v0.1.1-test: без фразы привязки в прошивке, Secure Link и умный FHSS выключены, CUSTOM_2640 в списке, но не выбран.

## Что изменилось

- Страницы Wi‑Fi (главная, опции, модель, обновление, пины, CW, LR1121) — тёмные карточки, янтарный акцент, жирный шрифт, шапка: прошивка, таргет, диапазон, состояние линка. Подписи по-русски, технические имена (UID, NSS, packet rate) оставлены. Шрифты системные, внешних запросов нет.
- Страница **Пины: LED / NSS** (`/hardware.html`) доступна из шапки. Заводской layout **не менялся** (Generic C3 LR1121: `led_rgb` = GPIO 8, `radio_nss` = GPIO 7). Если статусный LED на FlyFish 9624R тёмный, подберите `led_rgb` или `led` и сохраните.
- Выбор диапазона на LR1121 сохраняется в `options.json` (`gerda-band`) и применяется при загрузке. По умолчанию ISM 2.4. Старый ключ `domain: 1` (FCC915 в v0.1.1) **не** переключает радио на 915, пока sub-GHz не выбран явно.
- На сборке SX1280 (Ranger Nano) в списке только 2.4: ISM и CUSTOM_2640. CE/EU LBT показан, но недоступен.

## Диапазоны LR1121

| Выбор | Что делает |
| --- | --- |
| ISM 2.4 | Hop 2400.4–2479.4 МГц, 80 каналов. По умолчанию. |
| CE/EU LBT 2.4 | Те же частоты. LBT только флагом сборки `Regulatory_Domain_EU_CE_2400`, с LR1121 эта прошивка его не включает. Выбор ничего не меняет. |
| AU/FCC 915, EU 868, IN 866, AU/EU/US 433, US 433 Wide | Таблица sub-GHz ExpressLRS. В эфире она используется, когда packet rate — режим 900 или 433. |
| Dual + ISM 2.4 | Та же sub-GHz таблица плюс ISM 2.4. Packet rate D150 или D100 Full. |
| CUSTOM_2640 | 2600.4–2679.4 МГц. Не ISM, по умолчанию выкл. |

Sub-GHz и dual **не** работают с RadioMaster Ranger Nano: это SX1280, только 2.4 ГГц. Нужен LR1121 TX, антенна и RF-путь платы под полосу, и соблюдение местных правил частот. Выбор домена не подменяет packet rate и не затирает сохранённый UID.

## Прошивка

Привязка в файл не зашита. Wi‑Fi-обновление RX не трогает UID в NVS, если в прошивке нет `uid`. Targets Mismatch по-прежнему можно подтвердить («flash anyway»).

RX: Wi‑Fi `GerdaLRS RX`, пароль `expresslrs`, адрес `10.0.0.1`, файл для `Unified_ESP32C3_LR1121_RX`. TX Ranger Nano — файл той же версии. Фраза или UID на обоих концах должны совпадать; вводите их на вкладке модели (RX) или в опциях (TX), не стирайте flash.
